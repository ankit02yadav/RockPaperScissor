# 🪨 Rock Paper Scissors Game (C++)

A simple console-based Rock Paper Scissors game written in C++.

## 🎮 How to Play

1. Run the program.
2. Choose:
   - `1` for Rock
   - `2` for Paper
   - `3` for Scissors
   - Any other key to exit
3. The computer makes a random choice.
4. The result is shown: Win, Lose, or Tie.

## 🧠 Features

- Random computer moves using `rand()`
- Input validation
- Infinite loop until user chooses to exit

## 🛠️ Compile and Run

To compile:

```bash
g++ -o rps_game main.cpp
```
To run:
```bash
./rps_game
```
